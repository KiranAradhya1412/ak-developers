# Aradhya Solutions Website

This is a static frontend website with multiple pages:

- `index.html` - Home page
- `about.html` - About page
- `services.html` - Services page
- `photos.html` - Photo showcase page
- `courses.html` - Courses page
- `contact.html` - Contact page

The website includes a built-in AI-like virtual assistant that answers common visitor questions and guides customers to the right page.

## Running locally

Open `index.html` in a web browser to view the website. You can also open the other pages directly:

- `about.html`
- `services.html`
- `photos.html`
- `courses.html`
- `contact.html`

No server is required; the website works as plain static files.
